## 4. 转换中发现的问题与备注

1. **高松灯参考音频路径修正**：`config/config.json` 中写的
   `tomori/新しい模様の…（略）….ogg` 实际不存在；磁盘上是同名 `.mp3`。
   本阶段已按实际 mp3 转换并复制为 `prompt_wav/…（略）….wav`，阶段 2 需同步修正配置。
2. **mp3 参考音频**：高松灯 与 诗歌剧 的源参考音频是 mp3，Genie 服务器
   `/set_reference_audio` 不接受 mp3，已用 ffmpeg 转为 wav 放入 prompt_wav。
3. **目录结构**：按用户要求保存到 `F:/AiSound/Genie-TTS-onnx/CharacterModels/<角色>/`；
   ONNX 文件位于 `<角色>/tts_models/`（ModelManager 要求模型文件直接位于
   `onnx_model_dir`，与 Genie-TTS GUI 的目录结构一致），参考音频位于 `<角色>/prompt_wav/`。
4. **转换耗时**：首角色约 44 秒，后续角色约 3-4 秒；`Cache` 临时目录（项目根）转换后自动清理。
5. **显存**：逐个角色加载+合成（每角色独立进程）在 RTX 2060 上正常；
   阶段 4 若要在 GPU 上同时预加载多个角色，6GB 显存大概率不足，需按需加载/卸载。
