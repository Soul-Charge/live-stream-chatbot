弹幕 TTS 中间件程序设计要求
本项目旨在设计一个连接弹幕捕获工具(B站弹幕姬)与音频合成后端(本地部署的GPT-SoVITS 2pro)的非阻塞 HTTP 中间件服务 。整体程序设计必须满足以下核心要求：

1. 配置热更新模块：程序需在内存中维护全局配置并具备文件变动监听能力，确保配置修改后系统可自动热重载而无需重启服务 。
  配置内容包含以下部分

  * 基础设置
    捕获tts请求的ip端口等内容
  * 文本替换字典
    一个将tts请求文本部分进行替换的字典
  * 角色映射表
    通过请求部分匹配角色名并映射到具体gpt-SoVITS所使用模型，以及对应参考音频和参考文本的映射表

2. 请求解析与清洗模块：系统必须能安全解析传入的 HTTP 请求参数，执行必要的文本过滤（拦截屏蔽词、丢弃超长冗余字符），并依据动态字典完成文本内容的精准替换清洗 。

3. TTS 引擎适配模块：程序需维护一个异步任务队列以控制并发，将前端的文本与角色标识映射为目标 GPT-SoVITS 服务要求的完整参数对象，并向后端接口发起请求接收音频流 。具体的载荷参数结构（如参考音频路径、提示文本等）可能因不同第三方封装版本的接口存在差异

4. 流式播放调度模块：必须将获取的后端音频流直接桥接至本地媒体播放器的标准输入通道中进行顺序播报，并在单个音频播放结束后正确捕获退出事件以释放资源并调度下一任务 。
